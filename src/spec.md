# Specification

## Summary
**Goal:** Enhance the community map with required address validation, zoom controls, and visible location pins.

**Planned changes:**
- Make address field required in SetCoordinatesDialog with validation feedback
- Add zoom in/out controls to GlobeMap component for camera distance control
- Display user locations with visible pin markers on the globe

**User-visible outcome:** Users must provide an address to appear on the community map, can zoom in/out on the globe, and see pin markers showing where community members live.
